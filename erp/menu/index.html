Notas para tu análisis

Demo de diseño · datos ilustrativos

A · MENÚ HORIZONTAL
  • + Todo el ancho de pantalla queda libre para tablas y datos densos.
  • + Secciones principales visibles de un vistazo, sin clics.
  • + Con subniveles en cascada (estilo escritorio) escala a muchos módulos sin perder ancho.
  • − Las cascadas exigen precisión de puntero; lentas e incómodas en pantallas táctiles.
  • − La jerarquía profunda queda oculta: menor descubribilidad para usuarios nuevos.
B · MENÚ VERTICAL
  • + Escala a decenas de módulos con grupos y subniveles siempre visibles.
  • + Espacio natural para badges, contadores y estado de usuario/almacenamiento.
  • + Puede colapsar a solo iconos en pantallas estrechas (reduce la ventana para verlo).
  • − Consume ~260 px permanentes del ancho disponible.
  • − Menús muy largos exigen scroll interno y más recorrido visual.
Regla práctica: escritorio con ratón y uso intensivo → el horizontal con cascadas rinde muy bien. Aplicación web multi-dispositivo o con usuarios ocasionales → vertical, más descubrible.
